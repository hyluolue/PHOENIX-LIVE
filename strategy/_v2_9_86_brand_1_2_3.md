## 1. 品牌 1.0/2.0/3.0 核心

### 品牌 1.0 = 承诺 = "我"
- **核心**: 我怎么怎么样，我有什么
- **关键词**: 功能 / 卖点 / 差异化
- **问题**: 很难打动消费者，或者消费者存疑（"你说你好，凭什么？"）
- **案例**: 早期品牌大多停留在 1.0（"我们用最好的材料" / "我们的工艺最先进"）

### 品牌 2.0 = 品类 = "你"
- **核心**: 代入消费者，用户思维
- **关键词**: 场景 / 痛点 / 用户语言
- **代表**: 凉茶=王老吉 / 可乐=可口可乐 / 凉茶=加多宝 / 凉茶=和其正
- **范本**: "你怕上火，那喝王老吉" = 痛点+品类+品牌
- **金句公式**: 怕 X → 买 Y (王老吉范本)

### 品牌 3.0 = 信仰 = "我们"
- **核心**: 品牌和消费者站在同一边，是同一群人
- **关键词**: 价值观 / 精神 / 认同
- **代表**: 耐克 JUST DO IT / Patagonia 不要买这件夹克（环保）/ 苹果 Think Different
- **范本**: 信仰 = 行动号召 (Nike) / 价值观宣言 (Patagonia) / 反主流文化 (Apple)

### 1.0 → 2.0 → 3.0 跃迁规律
- 1.0 → 2.0 = 从"产品视角"切换到"用户视角" = 少说"我"多说"你"
- 2.0 → 3.0 = 从"用户视角"升级到"群体视角" = 从"我懂你"到"我们一起"
- 跃迁关键 = 找到用户**未被说出的共同身份**

## 7. 关键洞察

- **品牌 1.0 = 大多数品牌的天花板**: 长期停留在 1.0 = 永远在功能内卷,无法突破价格战
- **品牌 2.0 = 品类心智占位**: 凉茶=王老吉 是品类心智, 一旦占据,后来者极难撼动 (加多宝/和其正都没抢走)
- **品牌 3.0 = 跨代际的护城河**: JUST DO IT 35 年不动,因为它不只是品牌,是信仰 = 跟用户一起的身份认同
- **Phoenix 当前 1.0/2.0 完整,3.0 启动中**: 4 国 2.0 品类金句已落地,3.0 信仰金句 BD 已定,ID/EG/IN 待定
- **精神金句必须含"凤凰"**: 因为 3.0 信仰必须落到具体品牌 = "民族的世界"看不出是凤凰 (8/8 用户拍板)
- **"我们" 是最难写的**: "我"容易(我们有什么), "你"困难(你怕什么要洞察), "我们"最难(我们共同身份是什么)
- **3.0 信仰金句是灵感不是逻辑**: 4 国 3.0 精神金句 = 用户拍板灵感火花,不是推算 (V2.9.67 BD V6-2 教训)
- **品牌 1.0/2.0/3.0 跟 V2.9.85 4 张图互补**: 1.0 反对(图1) + 1.0→2.0 跃迁(图2) + 2.0→3.0 跃迁(图3) + 1.0/2.0/3.0 全链路(图4) = 营销理论全集
- **Phoenix "打不垮" = 4 国共同 3.0 信仰候选**: 1.0 极致产品(达克锈/氟碳漆) + 2.0 场景痛点(雨季/华人/沙漠/凉意) + 3.0 共同身份(打不垮人) = 三位一体
- **BD V6-2 "愿你在黑夜中被看见" = 行动型 3.0**: 字面(V4 夜间安全行动) + 隐喻(V6 致敬打不垮的人) = 1 句 2 层 = 完美 3.0 范式
- **IN 中英双百年对话 = 身份认同型 3.0**: 凤凰(1897) + Raleigh(1885) = 双百年品牌组合 = 共同身份(中英百年品牌人)
- **品牌 3.0 不能强行做**: 3.0 信仰金句是灵感,不是推算;用户对印度文化不熟悉就改用凉意(2.0 功能价值),而不是强行写 3.0 信仰金句
