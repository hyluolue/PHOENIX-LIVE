② 实战:淘汰一个"看起来很好"的高分候选

候选 「凤凰一直护着,你的不会伤」 —— 与支柱①完全同构,只看评分是 21 分(候选池第 2)。

但判据一票否决:"你的"既可解作车(车不伤 = 耐久 = ①),又可解作人(人不伤 = 安全 = ②) ⇒ 两个证据池都能接住 ⇒ 串味 ⇒ 淘汰。

后果是实打实的:顾客刚在支柱①的同一套物料里读过"你的不会熄",默认宾语是车 —— 整句白说。

⇒ 判据比评分更早生效,这是本次最重要的方法论收获。

③ 最高分候选 B 的否决留痕 + 复活条件

B「凤凰护着你,你不会有后怕」= 23 分(全池最高),证据承载与失败叙事风险都是满分。

否决理由:串味到支柱③。"后悔 / 后怕"在中文消费语境第一联想是购物后悔(后悔买贵了、买错型号)⇒ 直接落进支柱③「信得过 / 价格与厂家」的领地。四国对应词(অনুতপ্ত / menyesal / ندم / पछतावा)同样是"消费后悔",母语者改写也难逃离该语义。

复活条件:深访 Q7「读『你不会有后怕』,你想到的是骑车的事还是买东西的事?」

· "骑车" > 60% ⇒ B 的串味风险不成立,可提为主推 —— 这条会改本文件结论
· "买东西"占比高 ⇒ B 永久出局

⇒ B 不进任何物料,只在深访问卷里出现。

四国共同规律 —— 对 V2.9.97 规律的复用与升级

V2.9.97 发现:"熄"的对应词在四国全部带"希望/势头消退"的负面义 ⇒ 否定式天然是强修辞。
支柱② 复用的对应规律(反向验证通过):"危险"的对应词在四国全部是具体风险源名词 —— BD বিপদ / ID bahaya / EG الخطر / IN खतरा, 且四国都存在空间性动词(来 / 接近 / 碰到)⇒ "危险不会来到你身边"这个句式在四国的修辞强度天然一致,不需要逐国重写逻辑,只需母语者调措辞。

⇒ Phoenix 四国主张线的通用修辞家族(三支柱都能用否定式承载承诺):
① 否定一个「趋势」—— 熄 / 灭 → "不会熄"
② 否定一个「空间接近」—— 找上 / 靠近 / 碰到 → "不会找上你"
③ 否定一个「财务上限」—— 超 → "永不超 5%"
本地化必做的一件事(沿用 V2.9.97):让 ID / BD 官方号的本地员工各写 3 版,与参考译法一起送母语者盲评。 理由不变:参考译法只能保证语义正确,不能保证语感 —— 而主张线的价值恰恰在语感。
